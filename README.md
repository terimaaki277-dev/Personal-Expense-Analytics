# Personal Expense Analytics Dashboard

## Project Overview
This project is an interactive Personal Expense Analytics Dashboard developed using Microsoft Excel. The dashboard helps analyze monthly income, expenses, transaction trends, and category-wise spending using Pivot Tables and Pivot Charts.

## Features
- Income vs Expense Analysis
- Monthly Income & Expense Trend
- Category-wise Expense
- Monthly Transaction Count
- Income Source Analysis
- Average Expense by Category

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts

## Dataset
Source: https://www.kaggle.com/datasets/ramyapintchy/personal-finance-data
